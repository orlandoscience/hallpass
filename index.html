Quick start

  1. Open the page on the board. Double-tap an empty spot to go full screen.
  2. Pick your schedule at the top right (9th–12th or 10th–11th grade). The page knows the A/B days and the bell times by itself.
  3. The big timer is the 10/10 rule. Green = hall passes are open, red = closed (the first and the last minutes of class), blue = break. The bar shows where you are in the class.
  4. The ⚙ button (bottom right): double-tap it to open the settings (with your PIN, if you use one). Change the 10/10 minutes there, or turn on extras: hall pass buttons and log, sounds, rotating cards, weather.
  5. Lost? ⚙ → Quick setup → Basic brings back the simple screen.
Everything is saved on this device only. Nothing is sent anywhere until you type the school password for the hall pass log.

Sound Library

Add audio files already saved on this device (downloaded through the board's browser, a USB drive, a royalty-free sound site, etc.). Every file you add here shows up as its own option in both dropdowns above, so Warning and Bell Ring can each use a completely different file. This app can't fetch or convert audio from other websites itself — that risks copyright/terms-of-service issues — only files you already legally have on this device can be used.
A webpage can't automatically scan a folder for files sitting next to it — browsers don't allow that, for the same reason a website can't browse your hard drive on its own. The closest working equivalent: the picker below accepts multiple files at once, so if all your bell MP3s are in one folder, open the picker, select all of them together (Ctrl/Cmd-click or drag-select), and every one gets added in a single step.
Opens Pixabay's sound effects library in a new tab, pre-searched for "bell." Everything there is royalty-free with no attribution required.

Time Sync

Optional. If this school network has its own time server, put its address here and it's tried first, before any internet server — useful if this board has no internet access but can still reach the local network, or if you'd rather not depend on outside services at all. A browser can't speak raw NTP directly, but it can fetch a small JSON time endpoint like this one, the same way it fetches the 3 internet servers below. Leave blank to skip straight to those.

Security

Ask for a PIN to open the settings
New PIN (4–8 digits)
Open the settings by double-tapping the gear. With the PIN off, a double tap opens them straight away. The PIN also cancels a hall pass after the first 30 seconds.
All settings are saved on this device (browser IndexedDB), so they survive reloads. Times come from the OSHS 2026–2027 A/B block schedule and bell schedule sheet. Once the board has been opened online it keeps working without internet, and it updates itself outside school hours.
